# film v2 · P0 基线：冻结与逐层拆解测量

> 状态：P0 交付物（FILM_PRINT_RENDERING_PLAN §12 P0）。
> 用途：v2 之后的每一阶段都必须能对照这份基线证明"改了什么、没改什么"；
> 新功能不得靠未声明的层制造差异。

## 一 · 冻结

`tests/film_freeze/MANIFEST.json`：8 个 golden 场景 × 六联阶梯 ×
{portra400, velvia100}，共 88 个用例的 u8 输出 SHA-256（NumPy 参考路径，
DNGSCAN_FAST=0）。`tests/test_film_freeze.py` 逐用例重渲染并逐字节比对。
迁移语义按计划 §7.2：旧单 LUT 后端保持这份 freeze；v2 对直接光谱链 oracle
验证，不承诺与本 freeze 逐字节相同——但任何移动都必须经过声明的评审门。

六联阶梯（每档参数完整记录于 manifest）：

1. `agx_baseline` — 纯 AgX，无胶片层；
2. `curve_only` — 仅胶片明暗坐标（film_curve）；
3. `prefeed_only` — 仅感色分离（scene_transform @ 强度 1.0）；
4. `observe_combo` — 曲线 + 配对强度前馈 + 配对原色几何
   （golden 合成 bundle 无 WB 机制，WB 层如实缺席）；
5. `full_bounded` — 接管 LUT + 有界灰阶数字中性化（现行 off）；
6. `full_datasheet` — 接管 LUT + 数据手册漂移。

## 二 · 真实样张逐层拆解

五类样张（计划 §12 P0；样张在库外，工具对缺失文件跳过并报告）：
日光肤色=正午合照 `_SDI0238`、阴天植物=公园树荫 `DSC00225`、
钨丝场景=猫吧灯带 `_SDI0016`（**钨丝人像的替代样张**——已清点样张集中
无钨丝人像，如实声明）、霓虹高光=夜景 `_SDI0199`、深影室内=live house
后台 `_SDI0173`。

复现：`PYTHONPATH=. python tools/film_layer_decomposition.py --stock <卷>`；
原始数据 `docs/film_v2_p0_decomposition.json`（portra400）与
`docs/film_v2_p0_decomposition_velvia100.json`。

度量口径：输出 u8 域；可见% = 任一通道 >8/255 的像素占比；ΔL/ΔC 为 Oklab
均值；色相统计仅取 Oklab C>0.04 的像素。**注意**：深影样张的近中性暗部
像素色相本身不稳定，色相 p95 在这类内容上会被放大（如深影室内
velvia 曲线层 p95 95.9°），读表时以中位数为主。

## 三 · 基线结论（v2 各阶段的对照点）

1. **曲线层主导像素覆盖**（16–86%），方向是托亮暗部/整体密度（ΔL 均为正、
   随场景暗度增大）；色相几乎不动（中位 ≤1.7°）——曲线层是亮度层，符合声明。
2. **前馈层 @1.0 覆盖小而色度性**（0.4–16%）；Velvia 在植物场景最大
   （16.1%，色相 p95 18.3°），Portra 全场景 ≤2.5%——分离性格差异如实可测。
3. **observe 组合 ≈ 曲线 + 前馈 + 配对增量**的叠加，无隐藏层贡献。
4. **接管差（full−observe）是色相引擎的位置**：色相中位 3.5–15.7°，全表
   最大；ΔC 普遍为负（LUT 色度更收敛）。任何 v2 改动如果在 observe 侧制造
   了这个量级的色相移动，就是越层。
5. **层间漂移差随卷两极**：Portra 全场景可见% = 0.0（平均 Δ ≤2.6/255）；
   Velvia 幅度温和（平均 ≤8/255、色相中位 ≤3.8°）但在夜景/深影覆盖 60%+，
   方向为 ΔC 正（datasheet 保留的色度略高）。v2 的
   timing×neutralization 拆分必须保持这两个端点的量级。
