# 仅色度降噪（数字化修复）

> 状态：v1 已落地（2026-08-31，owner 批准的工作项）。CLI `--chroma-nr 0..1`，
> 默认 0 = 严格恒等。GUI 接线与 HDR 语义是记录在案的后续项。

## 0. 立场

本项目不做亮度降噪：LibRaw 解码路径完全无降噪、Core Image 路径钉在标定范围的
最少平滑端（`coreimage_decode.py` 实测记录），**保留的传感器噪声是诚实纹理**
——亮度噪点读作颗粒，这是有意的。感知上唯一读作"数字缺陷"的是**低频色斑**：
高 ISO 阴影里横跨几十个像素的品/绿色团块，来自逐通道噪声在 CFA 采样格上的
积分，任何解拜耳都够不着。本算子只清除这一段，并把"只"字做成结构性质而非
调参结果。它归类为**数字化修复**，与高光重建、clip retreat 同一伦理格子：
色斑是采样工件，不是光学信息。

## 1. 四条结构保证（tests/test_chroma_nr.py 逐条钉住）

1. **亮度永不动**：校正投影到零亮度子空间（P = I − 1·wᵀ，Rec.2020 亮度行），
   双线性上采样是线性算子、投影存活到全分辨率——实测 max|ΔY| ~1e-9。
   推论：auto-EV（亮度基）严格不受影响。
2. **细彩噪保留**：分析跑在降采样 spread 网格上（≤1408/2048），比网格格子细的
   色度结构（像素彩噪、胶片式细彩粒）根本进不了算子；恒等网格（小图渲染）时
   按传感器像素锚定跳过细层——实测像素彩噪保留 ~100%。
3. **大尺度真实色彩保留**：à-trous 残差层（粗于末细节层）不收缩——朴素的
   `C − lowpass(C)` 会连真实色彩场一起削掉，小波拆分把"去斑不去色"变成构造。
4. **高幅色边保留**：细节层内用 garrote 收缩 `removed = d·T²/(T²+d²)`——噪声级
   系数近全收、强结构只损 ~T²/|d|（软阈值的常数啃噬曾实测把大色块四层累计
   去饱和几十个百分点，探针记录 2026-08-31）。

## 2. 频带与阈值（modelled，非测量）

收缩频带声明在**全分辨率传感器像素**坐标（色斑是传感器工件，其尺度跟传感器格
走、不跟输出尺寸走）：[8, 128] px。层级选取 `atrous_levels_for(decim_factor)`：
level k 覆盖 `factor·2^k .. factor·2^(k+1)` px，与频带相交才收缩；级联始终从
level 0 平滑（à-trous 的 hole 间距只在渐进平滑图上不混叠），被保护的细层原样
通过。阈值 `T = amount·3·MAD/0.6745` 按层按通道取自该层自身系数的稳健中位
偏差。8/128/3 均为建模选择，等真实照片验收后再校。

## 3. 合成实测（512² 网格，amount=1）

| 口径 | 61MP 档（格≈6.8px） | 恒等网格（格=px） |
|---|---|---|
| 色斑带 RMS 残余 | 40%（能量 −84%） | 59% |
| 像素彩噪保留 | （亚格，不进算子） | ~100% |
| 真实色块色度保留 | 95% | 77%–91%（带内大块结构的 garrote 代价） |
| max&#124;ΔY&#124; | 7.6e-10 | 6.4e-10 |

## 4. 管线位置与一致性

场景意图 → scene transform（非 film-full）→ clip retreat → **色度校正**（本算子）
→ 胶片/AgX。校正图在 pass 0 整帧行带扫描构建（镜像所服务路径的逐 chunk 预处理，
`render._prepare_chroma_nr_map`），flat-chunk 应用与整帧逐字节一致（双线性同一
连续面，跨 chunk/band 无缝）。**胶片 pass A 读校正后的场景**（chroma map 传入
`_prepare_spatial_pass1`）——halation/bloom 源与色彩路径不得对同一张照片各执一词。

## 5. v1 边界（失闭，非忽略）

- **HDR**：AgX HDR formation 与 Ultrahdr AgX pair 无 chroma-NR 前置 pass，
  非零值直接 raise（SDR 腿修、HDR 腿不修会让 gain map 编码分歧）。胶片 pair
  不受限：两腿出自同一次渲染。
- **GUI**：未接线（service 不传该字段，默认 0，预览缓存安全）。
- **真实照片视觉验收待 owner**（同 P4 颗粒惯例）：阈值系数与频带在高 ISO 实拍
  上的观感未定版。
