# 色度降噪与纹理保护

[返回文档索引](README.md) · [导入实测噪声标定](NOISE_CALIBRATION.zh-CN.md)

当前色度降噪由独立噪声模型提供尺度，照片自身的结构用于降低收缩强度。它借鉴 darktable profiled denoise 的分工，保留本项目的场景阶段色度核，并非移植 darktable 的完整算法。CLI `--chroma-nr 0..1`、GUI「色度降噪」默认均为 0；导入标定不会自动开启。

降噪无法逐像素证明哪些变化是真实颜色。即使有准确的噪声标尺，接近噪声尺度的真实色度仍可能被削弱。这里不承诺无损，也不再把「保持亮度」或「保护部分小波层」解释为「只去色斑、不伤颜色」。

## 1. 噪声尺度来自哪里

有效来源为匹配的相机 shot/read 标定，或文件 Raw IFD 内适用的 DNG `NoiseProfile`；没有可用来源就跳过。CFA 块内标准差、绿色残差相关性和待处理波段的 MAD 都不再决定物理噪声量。

普通缺采样与明确未分辨的读噪分开处理。`read_noise_unresolved_isos` 同时约束 DN/e− 读噪曲线，禁止在失败点取值或跨失败点插值，独立有效的增益继续保留。没有独立文件模型替代时，模型为 `unresolved`，色度核跳过、HDR 尾部 SNR 门控为 0；不会回到全图 MAD 估噪。适用的独立 DNG 模型可以替代方差系数，但必须保留外部读噪失败的来源与原因，以及同一适用标定独立测得的频谱。普通读噪缺测同样不撤销频谱约束。即使 DNG 方差模型为 `valid`，已有 `measured-spectral-imbalance` 仍让当前色度核跳过、HDR 噪声因子为 0；频谱域外、相机/快门或 DN 尺度不匹配的测量不会借用。

设转换增益为 `g` e−/DN、读噪为 `r` e−、扣黑后的编码范围为 `R`，归一化 RAW 随机变量 `X` 的条件方差近似为：

```text
Var(X | μ) = a × μ + b
 a = 1 / (g × R)
 b = (r / (g × R))²
```

`μ` 为期望信号，用观测代替它是近似。JPTC 当前派生数据主要给出绿色标尺；把同一增益和读噪用于不同颜色平面属于 scalar-green 近似，不等于测量了完整 RGB 协方差。DNG 文件声明的逐平面系数按其颜色平面解释。

测量频谱的高频/中频功率比若小于 0.5 或大于 2，标为 `measured-spectral-imbalance`。这是独立测量摘要的保守启发式检查，不由照片纹理推断。此时保留有效 gain/read 模型，但当前粗网格独立噪声传播不适用，色度核跳过，HDR 尾部 SNR 门控受限。比值接近 1 只记为 `measured-spectrum-summary`，不能证明白噪声，也不能排除窄带峰或整行/列偏置；缺测为 `unknown`。

文件明确声明 `NoiseReductionApplied > 0`，或该声明非法时，独立白噪声假设不适用：即使外部标定匹配也拒绝该成像噪声模型，HDR 尾部 SNR 门控为 0、色度核跳过。`NoiseProfile` 的数值仍按前述来源优先级选择；处理声明属于对全部来源的兼容性限制。tag 缺失不证明 RAW 完全未经处理。

`NoiseReductionApplied` 的 `0/1`、`0/0` 和非零分子除以零分别保留为明确未降噪、未知和非法，不能都解释为 0。未知仅保留信息，不单凭它拒绝模型；非法声明按上述限制处理。

## 2. 从 RAW 到处理域的近似

滤波在经过解码、白平衡、颜色转换和曝光后的 scene-linear Rec.2020 上进行，不能直接把 RAW DN 或电子数当成该层阈值。当前传播记录实际使用的白平衡、相机到场景矩阵及曝光增益，以 CFA 感光点计数构造低频粗网格协方差。

支持的 GainMap 先组合增益，再以四点 Gauss 采样估计增益二阶矩；单个受支持的平滑 rectilinear warp 按每个 TCA 通道的局部 Jacobian 估计来源面积，放大采样数被截断，避免虚构独立样本。默认裁剪和方向变换沿同一坐标链应用。它们都是**低频 CFA 近似**，没有精确重建解拜耳、三次几何插值及相邻像素的全部空间协方差。

剪切、重建、越界和几何折叠等无效来源不参与校正；小波支撑碰到无效区域也不收缩。未知点变换、空间黑电平变换、多重 warp、fisheye 或其他尚未支持的传递关系会跳过并给出原因，不能因为场景图像能够显影就推断噪声传播也已标定。

Apple RAW 的内部降噪与解拜耳没有可用协方差标定，因此项目自己的可选色度核跳过。这不关闭 Apple 引擎内部处理，也不禁止独立传感器模型参与其他可用分析。

## 3. 波段与结构保护

B3 à-trous 分解在传感器像素尺度约 `[8, 128]` 的波段内收缩。层级用几何中心选取，边界只能精确到倍频层的约 √2 范围；滤波器也不是理想的硬频率截断。细节层之外的层和最粗残差不收缩，但真实颜色结构也可能处在被处理的波段中。

波段标尺来自实际保留的原生传感器窗口 `scene_sensor_window_shape` 和当前网格尺寸，按方向变换分别计算行、列的传感器像素比例 `sy/sx`，计入 DefaultScale、裁剪、half-size 及后续粗网格缩放。只有两个轴都符合目标倍频范围的层才参与收缩；不会仅靠 `proxy_scale` 推断半尺寸或非方形采样的波段。此标尺描述采样几何，不等于精确传播了镜头畸变、解拜耳及重采样的全部协方差。

每层、每色度通道的预期方差由独立模型传播得到。级联方差使用累计滤波器的平方权重，不能把同一次噪声经过多层平滑当作新的独立噪声。局部图像细节能量只用于估计高于噪声的信号能量：

```text
signal_var = max(local_detail_energy − local_noise_variance, 0)
T² = 9 × amount² × min(σn², σn⁴ / max(signal_var, ε))
removed = detail × T² / (T² + detail² + ε)
```

这是 BayesShrink 思路加 garrote 收缩。噪声模型不变时，局部真实结构增强通常会降低阈值，而不是把更多纹理解释成更大噪声。系数 3（平方后为 9）、频带和局部能量窗口仍是算法选择；不能把合成信号上的保护效果推广为所有照片的保证。

校正最后投影到零亮度子空间 `P = I − 1·wᵀ`，其中 `w` 是 Rec.2020 亮度行。因此本层 scene-linear Y 在浮点精度内保持不变；后续 tone、色域和量化处理仍可能改变最终输出亮度。色度纹理保护需要另外验证。

## 4. 管线位置与状态

pass 0 构造整帧粗网格校正图，按同一连续面应用到各行带或像素块，位于 scene intent 与 clip retreat 之后、AgX formation 之前。当前非线性 `scene_transform` 没有可靠协方差传播时会跳过。

适用时 SDR、独立 HDR formation 及 HDR pair 的两腿读取同一份场景校正图。GUI 和导出报告给出 `disabled`、`active-approximate` 或 `skipped` 及原因。强度 0 沿用原有恒等路径；缺模型、未知传递或不适用频谱不退回旧 MAD 阈值。

## 5. 验证与尚未覆盖的部分

当前回归覆盖无噪声的密集周期/随机色度纹理、已知独立噪声加真实结构、方差与矩阵传播、无效支撑、缺模型、读噪未分辨及 SDR/HDR 一致性。零噪声模型必须得到零校正；含噪输入同时检查噪声收益与真实色度幅度，不能只看亮度不变或整体 PSNR。

入口见 [chroma_nr.py](../dngscan/chroma_nr.py)、[noise_propagation.py](../dngscan/noise_propagation.py)、[test_calibrated_chroma.py](../tests/test_calibrated_chroma.py) 和 [test_chroma_nr.py](../tests/test_chroma_nr.py)。Rust B3 与 NumPy 对照证明实现等价，不能证明噪声模型成立或没有细节损失。

自己的 fp PTC、黑场和实拍颜色纹理验收仍需补充。尚未实现完整相关噪声传播、分频模型、行列条纹或固定图样修复；相机/模式适用范围、数据优先级和导入方法见[实测标定说明](NOISE_CALIBRATION.zh-CN.md)。2026-08/09 的旧 MAD 核测量不作为当前核的画质承诺；其失效与外部算法研究保留在[历史研究报告](reviews/NOISE_TEXTURE_RESEARCH_2026-10-09.zh-CN.md)。

空间临时内存档位由 `DNGSCAN_SPATIAL_BUDGET_MIB=512|1024` 选择，粗网格与行带尺寸共用这一预算；默认 512 MiB。
