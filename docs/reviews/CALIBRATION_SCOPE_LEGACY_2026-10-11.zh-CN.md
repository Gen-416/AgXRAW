起点：`main@d086eda6d3d314470065d9531b1182d91a3481fd`。对应 PR178 复审的 F01/F02；原报告使用 `1f3c8af`，其后 half/HDR 改动没有覆盖这两处问题。本轮使用独立临时标定库和真实 LibRaw 解码的合成 DNG 重跑原探针，两项均复现，源文件 SHA-256 未变。

PR #179 已合并为 `main@a5866d752084a3f74e0924c77e8f1ea3412ac177`。其后复审的局部遗漏见文末[PR179 后续收尾](#pr179-后续收尾2026-10-11)；以下原验证计数及机器记录保留历史范围。

## F01：显式限制不能随能力拆分消失

原实现对每项能力重新构建 CSV 条件时，会无条件删除机身、固件、读出、拍摄类别、RAW 几何及无损存储字段。用户后来在 JSON 中添加的限制也随之被删除；原探针中，机身序列号不匹配或缺失仍生成有效的约 2 e⁻/DN 外部模型。

修复将 `readout_scope` 分为两个有来源的层次：

- `automatic` 与 `automatic_sources` 来自实际 CSV 声明，每项能力仅使用自身依赖的条件；不能借用无关 PSD 的条件，也不能让 PSD 独有的机身限制污染独立增益。
- `explicit` 保存用户全局限制。兼容 `readout_contract` 中新增或修改的条件；这些限制贯穿安装、读取、能力视图和换文件重新绑定。若与该能力自身测量条件冲突，明确拒绝资格，不任意覆盖后继续采用。

新的测量包记录层次版本与 CSV 身份；读取时重新计算自动层，不信任可编辑的资格摘要。若要把已存在于自动层的同值条件明确提升为全局限制，应在 `readout_scope.explicit` 中声明，不能靠一次相同值的赋值猜测意图。

旧 JSON 没有层次信息时，无法从同值字段判断用户是否有全局限制意图。若该条件也由当前能力自己的依赖完整提供，可保留原有效域；若仅来自无关测量而会影响授权，则该能力标为未验证，并要求重新导入原 CSV 或明确声明作用域。保留原测量，不删除全部历史数据。没有逐表 acquisition 的手工 legacy 合同仍使用原有显式限制。

## F02：混合格式保留真实资格和供应者

原路径允许合格的 legacy 暗场成为新格式增益的供应者，但随后把 `qualification=None` 当作字典写入 `source_ids`，导致基础分析直接抛出 `TypeError`。

修复支持物理条件一致的新→新、legacy→legacy、新增益→legacy 暗场及 legacy 增益→新暗场。`None` 继续表示显式 legacy 合同，不补造已验证 CSV、来源 hash 或资格。电子读噪由当前 ISO 的 DN 读噪与合格增益换算，并保留两个供应者；任一依赖是 legacy，组合也不冒充全部来自新测量包的资格。

stored variance 保留自己的供应者、原始样本与测量状态。未分辨读噪、无效 stored variance、机型/读出/几何/编码域不匹配不能通过组合放行；不新增 ISO 外推范围。所有组合都保留依赖用于换文件重新匹配，旧格式资格也尊重重新绑定后的拒绝状态。合法 DNG NoiseProfile 回退保持独立，适用的异常频谱约束不因系数回退而丢失。

## 缓存与默认行为

预览/Analysis 缓存版本从 36 升至 37，标定指纹加入权限语义版本；原测量内容不变也不会继续复用旧的错误资格。缓存自动重建，无需删除私人测量库。

本轮不更换默认 half、RAW 前端、AgX/HDR 形成算法或压缩门限，也不新增默认降噪或个人像素校正。错误匹配的外部标定被拒绝后，分析结果可能合理变化；不能承诺这些输入与错误版本的成像逐位相同。

## PR179 后续收尾（2026-10-11）

起点：`main@a5866d7`。本节对应 PR179-F01 和同轮四项收尾检查，不重新打开已关闭的 PR178 两个 P1。

有效快门范围取各能力实际 CSV 依赖与用户显式范围的共同部分：CSV 为 `any` 时，公共 `shutter_override` 或 JSON 的 `readout_scope.explicit_shutter` 可以收窄到 mechanical/electronic/efcs；CSV 已限特定快门时，用户 `any` 不扩大范围，矛盾声明继续拒绝。缺少 CSV 快门条件不能靠声明取得资格。有效值进入能力视图、primary 绑定和换文件重新匹配，不能只保存而不消费。预览/Analysis 缓存升级至 38，权限语义升级至 3，旧权限不复用；原始测量及安装记录无需整体重写。

GUI、CLI 和标定文档统一为范围收窄语义；历史作用域歧义、快门/固件等冲突提供中文原因及重导入指引。配方文档补 v2 和必要参数资格，HDR 主图重参考文档补非 Archive 边界。早期任务记录添加后续状态链接，保留历史数据与测试计数。
