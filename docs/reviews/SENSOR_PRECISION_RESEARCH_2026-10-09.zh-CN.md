# 传感器精度研究：个人黑位、负噪声尾与联合色度

状态：**局部研究原型与合成验收完成，默认显影路径不变。** 本记录对应任务书 C01/C02/C07/C08/C09；生产标定缺陷与逐相位传播的实施状态另见[整轮任务记录](CALIBRATION_RAW_PLAN_2026-10-09.zh-CN.md)。没有个人暗场、平场或独立厂商参考的项目仍明确缺样本。

代码入口是 [sensor_research.py](../../dngscan/sensor_research.py)，回归为 [test_sensor_research.py](../../tests/test_sensor_research.py)。模块不由 RAW 导入或默认渲染调用。完整数值、运行环境及实际运行提交保存于 [sensor-precision-20261009.json](../assets/pipeline/sensor-precision-20261009.json)。记录基于带本轮工作修改的源码，不能把其基准 commit 单独视为已包含所有实验代码。

## C01：个人浮点黑位合同

`PersonalBlackCalibration` 描述一个实测 ISO、机身序列号、读出身份、曝光区间和来源 hash。温度、固件及失效日期若有声明，必须匹配；缺失条件不能满足有界声明。每个 C00/C01/C10/C11 是空间位置，必须明确测得，不能从两个绿色记录补成四个实测通道。当前原型不插值 ISO，也不接公共 CBLD 覆盖。

数据域为 **LUT 已完成、Stage 2 尚未开始的线性化 RAW DN**。`signed_black_correct()` 总是生成工作副本，保留原始数组，并同时返回来源、身份、逐相位系统不确定度和负尾比例。负尾只是统计诊断，不是坏点掩码。所有标定数值、有效条件及不确定度进入身份 hash；修改其中任一项，身份即变化。这个身份尚未接入生产像素缓存，因为默认路径没有启用个人像素黑位覆盖。

两种语义明确分开。`absolute` 用实测相位黑位替换元数据的相位基线，仍保留 DNG 空间黑位的残差；调用者必须提供原元数据相位基线。`residual` 在完整元数据黑位之后额外扣除实测残余。两者在等价校准下得到同一结果，避免元数据和个人黑场重复扣黑。实测均值的系统不确定度不并入逐像素随机方差，也不宣称精确零偏置。

合成弱中性灰、空间渐变、G1/G2 黑位差、错误机身／读出／ISO／曝光／温度／固件、过期校准及身份变化已覆盖。**尚未将这些合同连入默认 RAW 解码**：下一步需要同机身、匹配曝光与温度的真实暗场，验证 LUT／opcode 顺序、传感器原点及跨 ISO 适用性。

## C02：近黑截尾与 signed CFA

实验对比实际 `spatial_black.apply_to_working()` 与保留有符号残差的参考，使用 512×512、四相位读噪 σ=3/4/5/6 DN、四种小数黑位、五个 0..4σ 信号档及空间黑位渐变，共 20 组。小数黑位 0.25、零信号一组为：

| 量 | 有符号残差 | 生产空间黑位工作缓冲，换回原 DN |
|---|---:|---:|
| 均值 DN | 0.00614 | 1.79831 |
| 方差 DN² | 21.46061 | 7.51399 |
| 负尾比例 | 52.21% | 0 |

上端 loss mask 仍为零，这是其现有定义；不能把它解释成“没有近黑分布改变”。方向与零均值高斯截零后的均值 σ/√(2π) 一致，具体数值还含 ADC 舍入及各相位不同 σ。

`signed_bilinear_bayer()` 在浮点扣黑后应用明确的相位 WB，再进行归一化线性插值，保留负值。四种 Bayer 位置、非整数黑位和两绿不同增益均有参考测试。它不含自适应重建、高光恢复、复杂 opcode 或完整几何传播，**不是 LibRaw 的功能等价替代品**。

另生成 12 份条件组合的真实可解码 DNG：bilinear/DHT、两种 WB、信号 0/2/8 DN；每组检查 −2/0/+2 EV 的 SDR 与 HDR。生产解码和实验参考采用同一文件矩阵、明确的白黑归一化和固定生产 tone plan，不拟合自由 gain/offset 来对齐。记录显示近黑 scene 均值偏置与后续成像差异。非线性显示形成仍会改变噪声均值，因此保留 CFA 负尾不等于最终屏幕黑位自动完全无偏。

本机 512×512 signed bilinear 单次约 8.4 ms，调用内跟踪分配峰值约 19 MB，RGB 输出本身为 6 MiB。这里只是小图测量，不是全尺寸性能承诺。float64 RGB 在 24MP 时仅输出就需 576 MB（十进制），还不含工作图与临时缓冲；当前简单实现不宜直接用于大图默认路径。若继续产品化，应先做分块 float32、有符号校正顺序与多种重建质量比较，保留现有不支持传播时的门控。

## C07：固定结构与时域噪声分开

`dark_stack_products()` 单独保存均值偏置图、同像素时域方差、相邻对差分方差、均值图的不确定度、行列均值及热像素候选。所有输入必须是同一 ISO、曝光、温度和读出的独立暗场，并以调用者验证的标定身份标记。候选不是坏点修复；产品默认 `correction_authorized=False`。原型不从单张夜景估计或减去条纹。

64 张训练暗场与 32 张未参与拟合的留出帧，含已知行列偏置、热像素、σ=2 DN 随机噪声及额外弱结构。扣除训练均值图后，留出均值误差从 5.0316 降到 0.1881 DN²；留出帧时域方差在前后均为 3.8735 DN²。均值图自身还含约 0.0624 DN² 标定方差，不能当作完美固定真值。这个实验说明分离方式可用，不证明其他温度或曝光时长可复用同一图。

真实机身产品化仍需要匹配条件的多帧与独立留出帧、失效范围及坏点策略。两个一维 PSD 没有空间相位信息，不能替代这样的均值图。

## C08：完整二维色度协方差

`joint_chroma_shrink()` 使用 Rec.2020 亮度权重的正交零亮度二维基，将完整 3×3 协方差投影为 2×2，特征分解白化后按向量范数联合收缩，再还原色度。奇异、非对称、非正半定及条件数过大的模型明确拒绝，不通过任意加对角项获得虚假的精度。

96 组细线、织物、色边、亮度边、八种颜色方向及三档幅度记录了色度幅度、色度向量角误差和 MSE；同时测量现有生产核。**原型只处理一个已知线性频带，生产核有多尺度结构保护，两者不是等价算法，也不构成公平速度排名。** 联合原型的最大亮度变化约 3.4×10⁻¹⁷；这只验证亮度约束。它仍可能删除弱色度结构：本矩阵的幅度回归系数最低约 0.64，且低信噪条件下的角误差明显。

因此不把联合收缩接为默认核。完整协方差值得继续研究，但准确噪声标尺仍不能逐像素判定真实微弱结构。应在匹配标定、弱色织物与低噪声实拍上比较，再决定是否整合到现有结构保护策略。

## C09：量化边界与误差预算

| 阶段 | 当前域与边界 |
|---|---|
| LibRaw 解包／LUT | 存储编码到线性化整数 RAW；不可逆 LUT 的 Stage 1 不声称可恢复 |
| 空间扣黑 | `(raw-black)*65535/(white-max_black)`，clip 后最近舍入到 uint16；负尾丢失 |
| Mosaic GainMap | 原始或已归一化工作 DN，增益后 clip，再 `astype(uint16)` 截断 |
| Stage 1/2 point-op | 依声明归一化，clip；整数工作缓冲最近舍入 |
| LibRaw WB／解拜耳 | 内部整数缩放、clip，16-bit camera RGB 交接 |
| Stage 3 point-op／恢复高光后的镜头处理 | 已修正的浮点相机域；WB 共轭与逻辑白点明确 |
| Camera RGB→scene、AgX／HDR | float32，矩阵后的负值和扩展高光不统一截为 SDR |
| 最终 JPEG／HEIF | 显示形成后按目标位深量化；提高出口位深不能恢复前级截尾 |

对近黑、空间梯度与近白信号，比较每步截断、每步最近舍入、延迟到最后最近舍入。12-bit 原始 DN 梯度上的四次亚 DN 增益，平均误差分别约 −1.996、+0.00235、−0.000061 DN，RMS 分别约 2.058、0.498、0.289 DN。每次操作仍保留上端 clip，所以延迟整数化没有偷换高光裁切策略。

这些是合成误差预算，不能换算成真实 fp 文件的普遍可见改善。默认 GainMap 量化没有因此改动；更换边界需要真实标定与算子顺序验收，也应避免一次操作的数学改善引入与 LibRaw 不兼容的后续尺度。

## 复现

在安装了项目锁定依赖的源码仓库运行：

```sh
python -m unittest tests.test_sensor_research tests.test_phase_noise_model -q
python tools/validate_sensor_precision.py --size 512 --include-pipeline \
  --output /tmp/agxraw-sensor-precision.json
```

`--include-pipeline` 使用仓库测试夹具生成 DNG，实际执行固定 rawpy/LibRaw 和生产 SDR/HDR 形成；不要求个人文件，也不把合成验证计为实拍标定。时间与内存是本机单次测量，重复运行会变化。机器记录包含所有矩阵与数据域，而不仅是一项均值或 PSNR。
