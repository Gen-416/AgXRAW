# PR177：Collect 逐文件采集合同与独立能力组合

审查基线为 `7004fafd60c79864e9939bf79b8ce74d82e85bac`。本次修复 PR177-03；固件／序列号的文件读取入口由同轮 PR177-02 单独处理。没有重新标定用户相机，也没有将普通实景当作暗场／平场。

## 逐文件声明与组关联

每个新导入 CSV 都按内容 SHA-256 保存自己的采集条件。新增 `dngscan-collect-acquisition-1` 记录包括测量种类、各表实际声明、逐字段来源和缺失列表，以及逐能力的来源文件、缺失字段和资格。

`association_contract` 表示哪些文件可以无歧义地归到同一候选组；`common_contract` 仅包含所有参与文件均明确声明且一致的条件。唯一候选组不会把 gain／PTC 的快门、LUT、ADC 或固件变成 dark 已证明的条件。本版没有引入跨文件自动继承；未来若增加批次共同声明，需要独立来源合同。

Camera、快门、压缩、完整 RAW 栅格、CFA、线性化和 ADC 步长需要明确声明。机身、固件、读出、拍摄类型、DN／方差域和 decoder 身份只要用于该组的条件，也需保留每份测量的完整性。DNDomain 与 VarianceDomain 分别保存，不能将 DN 与 DN² 当作同一种单位。SensorMaximum 是独立的编码端点，不由 ADC 位深或其他文件自动补齐。

当前运行时仍按整份 profile 的物理域选择统计模型，因此任何参与表的必要条件不完整，会使该 profile 的统计能力保持 `unverified`，组状态为 `partial`。数值测量仍保留供诊断，但不会只因拟合出了 gain／RN 曲线就取得模型许可。基础 RAW 显影继续可用。已知非恒等 LUT、未分辨 ADC 步长和不可信压缩声明也不能得到合格统计能力。

manifest 的条件范围、runtime_contract、能力和最终导入记录共用这些状态。JSON 读取时重算资格，不能只编辑保存的 `issues` 或 `qualified` 摘要来删除缺测条件。新版包进入历史打包 Collect 加载器时也保留这道检查。

## 独立能力组合

原组合器要求整个 acquisition_contract 字典相等，实际分包 CSV 的文件名／覆盖列表天然不同，因而无法组合。现在只比较明确列出的物理域字段，保留来源与逐文件资格；机型、快门、readout_contract、DN 参考跨度仍须严格相同。缺测、不同 LUT／ADC／decoder 或不同模式不会因同型号而拼接。

独立暗场只有明确声明 SensorMaximum，且它与测得黑位构成一致的 DN 跨度时，才能给出供组合检查使用的 reference_dn_range；缺端点时继续无资格。它不会从另一包的 PTC 或 nominal bits 借用白点。组合后的 gain、read noise、stored dark variance 继续分别记录来源及各自测量合同，频谱约束仍保留。复制暗场常数曲线时同步保留该暗场的统计估计合同；若 base 已有常数曲线，则保留 base 的数值、合同和来源，不因补充了另一份读噪而改写归属。

## 验收

运行 14 个相关模块共 **167 项用例，全部通过**（NumPy 路径，2026-10-10 本机运行）。该计数包含同轮文件身份入口的相关回归，不与其他全量或重叠计数相加。

新反例覆盖官方 writer ZIP／改名目录、仅在 gain 或 PTC 中声明 shutter／compression／linearisation／ADC、互相矛盾的条件、保存摘要被修改，以及真实 CSV 分包进入生产分析。

分包验收采用仓库固定版本官方 writer 生成的合成统计表：PTC 包另明确声明已知的黑位，dark／spectrum 包另明确声明已知的白点；这些补充声明与原始 CSV 一起参与内容身份。它们不是未经补充的官方导出已经包含端点的证明，也不是用户相机实测。

两包独立安装后，真实可解码的匹配合成 DNG 经过 `load_raw()`、`find_priors()`、`analyze()`，得到有效组合模型；gain 约为 2 e⁻/DN，归一化常数方差为 `4 / 3995²`，独立频谱来源仍在最终模型中。改变候选暗场的 ADC 域后不能组合。旧回归夹具原先依靠从暗场继承 PTC 条件，现已在每表明确补齐采集头，未放宽产品门控。

传统无逐文件记录的 JSON／旧打包资产沿用原合同，不能从其历史摘要补造新的逐文件证据。此前 manifest 导入的用户 Collect 包若没有逐表合同，会明确显示 `measurement-acquisition-reimport-required`，统计能力保持未验证；它们不会因新文件身份适配器开始提供固件值而意外重新取得许可。原记录留存供检查，重新导入原包会获得新合同与内容身份，合格的新记录优先匹配。迁移不误伤传统手工 JSON 与历史公共资产。
