# dngscan 胶片观察位置：设计与实现合同

> 文档用途：记录"胶片观察位置"功能群的设计决定、数据出处策略、生产合同与验收边界。
>

> 区分、双模式分工的信任边界、缺失数据清单机制）仍然生效；交付范围早已超出
> 本文的首发清单——现役 20 款胶片 + 5 影院引用变体、联合 Y×M 色头
> （joint-lms-npz-v4，SHA-256 内容钉扎）、full 模式烘焙光谱链 65³ LUT、
> schema v4 介质原生黑位（零标定杂光）。凡本文与现状冲突处（首发双旗舰、
> 残差门数字、观看闪光、比率场运行时、色头小网格、层间漂移开关实现），以
> [ARCHITECTURE.zh-CN.md](ARCHITECTURE.zh-CN.md) 为准；对应段落已加"现状注"。
>
> 定位一句话：**一个带有"可标定的胶片观察位置"的 tone mapping 工具，不是胶片模拟器。**

## 0. 结论先行

胶片"看"世界的方式可以分解为四个独立的、各有公开出处的层，每层在 dngscan 管线里
都有唯一正确的位置：

```
解码            [镜前滤镜]         [光谱前馈]          AgX formation        交付
WB=声明观察位置   改变入射光         更换观察者           显影曲线坐标          SDR/HDR
固定色温(已完成)  Wratten 透过率     胶片光谱感度         特性曲线拟合预设      不变
```

三个准入条件（继承自 WB 固定色温的先例）：

1. **有公开标准或数据手册作为出处**——不接受"调到好看为止"；
2. **在管线四层里有明确的层位**——不接受跨层烘焙（这正是 LUT 的病）；
3. **拟合质量可测量、可报告**——每个预设携带 `source` 与 `fit_residual`，
   如同 WB 的"0.1% 吻合"和前馈的 `confidence`。

明确的非目标（划出"胶片模拟器"的边界）：

- 不做颗粒、halation、相纸纹理、扫描仿真、片基色罩视觉化；
- 不做逐像素光谱上采样（从 RGB 猜光谱是不适定的；我们在 RAW 端工作，
  相机的光谱积分是真实发生过的）；
- 不替换 AgX formation——AgX 的 C1 曲线族、path-to-white 与全部既有合同原样保留，
  胶片曲线是这个参数空间里的**具名坐标点**，不是另一条管线；
- 不牺牲 HDR——胶片性格必须能进 Ultra HDR 交付，这是本功能群与市面所有
  胶片工具（含 spektrafilm）的根本差异点。

## 1. 与 spektrafilm（agx-emulsion）的关系

它做正向全链模拟（RGB→猜光谱→胶片感度→耦合剂→颗粒→相纸→扫描），锁定 print-referred
SDR；我们做分解式标定（RAW→声明观察位置→分材料色彩分离→参数化显影曲线），保持
scene-referred 直到 formation，因此 HDR 可达。两者在"数据手册的机器可读化"上握手：

- 它整理的胶片光谱感度、染料密度、特性曲线数据（GPL 生态，与本仓库许可兼容）
  作为首选数据源，逐文件在 `dngscan_assets/spectral/` 的 README 与 NOTICE.md 中
  记录出处与许可；
- 它的相机端空白（输入 RGB 被假设为真值，相机光谱指纹未建模）正是我们前馈层的
  存在理由；两个项目互补，不竞争。

## 2. 第一层：镜前滤镜（Wratten 转换滤镜）

### 2.1 物理与层位

滤镜是镜头前的玻璃：`I'(λ) = T(λ)·I(λ)`，作用于光、先于感光。数字模拟位置：
解码（含 WB）之后、前馈之前的 scene-linear Rec.2020。经传感器积分后，
光谱滤镜到一阶是一个**全局 3×3**（近对角）矩阵；与逐通道 WB 增益的差集中在
饱和材料与窄谱光源——那个残差就是"滤镜感"。

### 2.2 为什么不是 scene_transform 预设

（2026-07-30 重审改写）滤镜的**第一语义是把光源搬到胶片的校准点上**：日光卷 +
钨丝灯 + 80A，光 × 滤镜 ≈ 设计光源，**在胶片自己的参考系里中性轴根本不动**。
"移动中性轴"只是在流水线里单独应用滤镜矩阵时的现象——WB 已先中性化，矩阵再
作用上去的副作用视角。配对使用（WB 3200K + 85B 在日光下 / WB 5500K + 80A 在
钨丝灯下）时两者相消回到近中性，前馈窗口全程有效（组合近似闭合但不精确——
残差是历史工作流的指纹）；单独使用（故意色偏）是**声明的退化情形**：真实胶片
在此深入分离拟合从未覆盖的激励区，前馈窗口按拟合域淡出为恒等是拒绝外推，
不是失效。

前馈合同明文"中性轴不变"，而滤镜重新表达光本身——两者持有不同的不变量，
故滤镜作为独立小阶段实现：

- 新模块 `dngscan/lens_filter.py`：全局矩阵一次乘法，`strength` 无——滤镜没有
  半片玻璃，只有装或不装；
- CLI `--lens-filter {none,85,85b,80a,81a,82a}`；GUI 放在"RAW 解码"卡
  （它是采集光学，不是颜色创作）。

### 2.3 验收门

规范决定：滤镜从**出版 mired 常数**构造（原计划的 T(λ) 光谱积分因无可靠机读
数据源而废止——手工数字化会给声明出处掺入转录误差；光谱精修保留为"待机读
数据"的声明升级路径）。已建成形态的描述见
[架构文档·胶片观察](ARCHITECTURE.zh-CN.md)。

验收门（`tests/test_lens_filter.py`）：

```text
mired 算术：各滤镜的声明位移落到出版目标色温（85B: 5500→3200K 等）
互逆性：+131 与 -131 mired 矩阵乘积 ≈ 单位阵（对称锚对的构造保证）
曝光因子：出版滤镜因子记录为元数据、从矩阵中归一化移除（数字域不丢光子）
组合闭合：滤镜+失配 WB 的残余偏移有界且被记录（历史工作流的指纹，是特征）
齐次性：曝光乘 2 输出乘 2 精确成立（线性矩阵天然满足，测试钉住）
管线接线：bundle.lens_filter 到 scene_intent 的传导
```

## 3. 第二层：光谱前馈转正（胶片作为观察者）

### 3.1 设计不变

机制零改动：分材料色度窗口 + 约束 3×3 + 中性轴保持 + von Kries 窗口搬运 +
置信度缩放——全部沿用。改变的只有**拟合目标**：把"数字化 ALEV 猜测"换成
"数据手册印着的胶片光谱感度"。在现有标定器的框架里，**胶片就是另一台相机**：
`calibrate_skin_matrix.py` 已支持双机拟合，替换目标侧 SSF 的 CSV 即可复用全部
基础设施（190 反射谱 profile、分类别拟合、泄漏矩阵、置信度报告）。

### 3.2 语义澄清（写进 docstring 的合同）

前馈胶片预设映射的是**色彩分离差异**（"Portra 的光谱感度会把这些材料的颜色
分离成什么关系"），不是密度/色调（那属于 formation 层）。胶片三层曝光量被当作
三刺激空间，经与相机侧完全相同的 190 反射谱流程 profile 到 Rec.2020——两侧
对称，误差同源可比。

### 3.3 交付物与验收

- 数据（首发范围；现役已扩至 20 款 + 5 影院变体）：**双旗舰首发——Kodak
  Portra 400 与 Fujifilm Superia X-TRA 400**
  （西方与东方各自最深入记忆的一卷）。相机侧维持 A7III + 热镜模型代理，
  `confidence` 机制如实降权（换真实测量时预设自动受益，机制不变）；
- Superia 专项注记：
  1. **第四感色层**——Superia 的青敏第四层是它在混合光下色彩记忆的一部分。
     若 datasheet 暴露第四层感度曲线，前馈把胶片当作**四通道观察者**处理
     （profile 拟合从 3×3 扩为 3×4，标定器小改）；若仅并入三层曲线，
     按三层近似并在预设 note 里如实标注；
  2. **数据自洽性**——spektrafilm 作者的实测经验：富士 datasheet 数据自洽性
     低于柯达。预期 Superia 预设的 confidence 系统性低于 Portra，这是数据
     现实的诚实反映，不做人为拉平；
  3. **版本钉定**——Superia X-TRA 400 历经 1998/2003/2006 三版并于 2024 停产
     （继任"Fujifilm 400"为美产乳剂，非同一款）。预设 `source` 必须写明
     所据 datasheet 的版本与年份；
- 预设：`portra400_d55` 与 `superia400_d55`（材质窗口沿用
  skin/foliage/cyan/neutral/magenta，按需增 sky 类——Superia 的
  第四层对荧光/混合光场景的意义可能要求增补 fluorescent 窗口，实测定），
  每类携带 `source / confidence / fit_residual`；
- 测试：现有前馈套件全部沿用（中性轴、置信度缩放、WB 搬运、分量窗口），
  新增：各类拟合残差入预设并断言 ≤ 阈值；泄漏矩阵越界告警；
- A/B：`tools/hdr_ab.py` 风格的对比页，回归样张 × {关/开} 前馈，
  存 `docs/assets/`。

## 4. 第三层：formation 曲线预设（AgX 参数空间里的具名坐标）

### 4.1 设计决定

AgX 不被替换——它就是胶片曲线族（卤化银词源、H&D 型 toe/shoulder、逐通道
path-to-white 对应染料耦合剂耗尽）。"Portra 预设"= 在 AgX 参数空间
（contrast / toe_power / shoulder_power / latitude_lo/hi / black_ev / white_ev）里
由数据手册特性曲线**最小二乘解出的一个点**，携带出处与残差。

关键决定：**胶片预设锁定整条曲线参数（含端点），场景自适应关闭。**
理由：胶片响应是固定的——同一场景永远得到同一密度，"整卷一致"正是用户
选择它的原因（与 WB 固定色温同一逻辑）。黑白端点由数据手册直线段宽容度给出，
不再随场景漂移。EV0 → 0.18 的 pivot 锚定合同**必须保持**：拟合时先解曝光偏置
把胶片的中灰放置对齐到 0.18，再拟合形状。

### 4.2 HDR 组合（旗舰场景）

胶片预设 + HDR：预设曲线是 K 以下的 body，可靠尾部照常挣取 K 以上的
log-stop shoulder——"Portra 的身体 + 诚实的 HDR 高光"，市面无第二家。
预设的 contrast 值必须进 α 域扫描（细分机制已就位，扫描只为刻画禁用区不存在）。

### 4.3 交付物与验收

- 离线工具 `tools/fit_film_curve.py`：输入数字化特性曲线（负片 + 端到端
  正像），输出 AgX 参数 + 残差报告 + 目标/拟合曲线对照图；
- 数据：Portra 400 与 Superia X-TRA 400 特性曲线 CSV（datasheet 数字化，
  标注版本；两款并行走同一工具，残差各自报告）；
- 管线：`ToneCompressionPlan` 增加 `curve_preset` 具名来源；
  `build_render_plan` 在预设激活时跳过场景自适应压缩编译（复用
  用户 adjustments 的 override 通道，明暗微调仍可叠加——微调作用于
  预设坐标附近，且如实报告）；
- 测试门：

```text
拟合残差（首版门；现行门=全族 rms 0.10 / max 0.25、theatrical ×1.25，
        另有介质原生验收 rms ≤ 0.07，见 tests/test_film_curve.py）：
        RMS ≤ 0.08 stop（-6..+3 EV），最大 ≤ 0.15 stop，写入预设；
        每个预设的存储残差与复算值互差 ≤ 0.005 stop（回归钉定，
        天花板之下不允许漂移藏身）
  （标定注：合同初版的 0.05 是数据到来前的猜测。实测 AgX toe 族与
   Portra/Endura 相纸膝部的结构性距离为 RMS 0.058——放宽参数边界只能
   改善 0.001，证明这是曲线族距离而非优化不足。门限按实测加余量重标，
   与 delivery 门限重标定同一先例；Superia 实测 0.021，远在门内。）
EV0 = 0.18，误差 ≤ 1e-5（沿用既有合同）
C1 编译有效：compile 不失败、单调、端点契约全过
α 扫描：预设 contrast × 全 headroom 轴 × tail 域，权威曲线全部可编译
SDR 冻结：预设关闭时逐字节不变
HDR：预设开启时 formation/delivery 全套测试通过
```

## 5. 组合语义与 UI

"Portra 400"作为一个**组合预设**呈现（GUI 一个下拉、CLI 一个
`--film portra400`），展开为三个独立声明：WB 5500k + 前馈 portra400_d55 +
曲线 portra400。三层各自可单独开关（高级用户），组合预设只是捆绑——
**没有任何一层在另一层里烘焙**。描述行如实报告：
`胶片观察：Portra 400（WB 5500K · 分离 conf 0.7 · 曲线残差 0.03 stop）`。
投递报告面板增列当前观察位置。

## 6. 实施顺序与提交边界

按价值与依赖排序，每步全套测试后提交：

1. `docs:` 本合同入库；
2. `data:` 胶片光谱/曲线数据导入 + 出处与许可记录（NOTICE.md、spectral/README）；
3. `tools+tone:` fit_film_curve + 曲线预设管线 + α 扫描 + 测试
   （最大可见价值，先行）；
4. `prefeed:` 胶片 SSF 拟合目标 + portra400_d55 预设 + 测试 + A/B 页；
5. `capture:` lens_filter 阶段 + Wratten 推导 + 测试；
6. `ui:` 组合预设（GUI/CLI）+ 描述行 + 投递报告列 + 使用说明/README 双语更新
   + 对比图。

粗估：3≈1 天，4≈1 天（数据工程为主），5≈半天，2/6≈各半天。
每阶段独立可交付，中途停下不留半成品层。

## 7. 风险与开放决定

- **数据许可**：spektrafilm 数据复用前逐文件核对许可与出处链（任务 2 的门槛）；
  Wratten 曲线若无现成机读数据则自行数字化并公开 CSV；

  这是已知边界，不阻塞（同 REVIEW_FINDINGS 时代的结论）；
- **明暗微调与固定曲线的关系**：默认允许叠加并在描述行报告"偏离预设"；
  若实测发现语义混乱，收紧为预设激活时锁定微调（开放决定，实测后拍板）；
- **首发胶片**：Portra 400 + Superia X-TRA 400 双旗舰（东西方记忆之卷；
  Portra 数据最全做基准，Superia 检验富士数据链并首验四通道观察者路径）；
  第二批 Ektar 100 / Vision3 250D / 一款黑白（黑白只需曲线层 +
  全局去饱和语义，另议）。

逐步核对本管线的胶片映射计算：

| 光源 | 合成 SPD | `illuminant_spd`（D55/A） | 同构 |

### 8.1 观看条件完整的忠实翻译（2026-07-30 合同修订）

审计发现旧表述自相矛盾：若"忠实翻译"= 原样搬运报告，则反转片的 T^(1/1.5) 是
一次色貌干预、违反"不做色貌建模"；若不补偿，电影链（Vision3 → 2383 放映拷贝）
把为黑暗影厅设计的对比度原样搬进明环境显示又显然错误。修订裁决：

> **忠实翻译 = 翻译"观察者在其原生观看条件下的报告"。** 一份报告只有连同
> 阅读条件才完整——引用 Cineon 码值不带 95/1023 校准点，数字全对、含义全错。
> 搬运到目标观看条件时补上两条件之间的经典 surround 项，**且只补这一项**。

| surround | γ | 适用介质 | 出处 |
|---|---|---|---|
| dark | 1.5 | 幻灯投影、影院放映拷贝（2383/2393） | Bartleson-Breneman（Fairchild 2013, 3rd ed.）；摄影成像科学传统（Giorgianni-Madden） |
| dim | 1.2 | 广播电视惯例 | 同上 |
| average | 1.0 | 反射印片、**本管线声明的交付条件** | ISO 3664 观片传统 |

翻译指数 = γ_target / γ_native（`tools/fit_film_curve.py` 的
`surround_exponent`）。推论：反转片与电影链同取 T^(1/1.5)（2026-07-30 重拟后
电影链残差全线减半，Verita rms 0.104→0.053，Vision3 全系 ≤0.053，contrast
~2.2→~2.0——被除掉的正是放映补偿）；相纸链恒等**由条件重合推出而非假设**。
同日第二修正：地板常数改为与标量目标同构的**亮度合成**（此前为通道算术平均，
Velvia 的地板高出亮度渐近线 0.57 stop，曾被误判为"AgX 族与幻灯片的结构距离"），
反转片全系降至 rms ≤0.022 且钉界清零，反转片例外门退役，全族门收紧至
rms 0.10 / max 0.25（ENGINEERING_NOTES 案例 8 续）。
已声明残差：sRGB 严格参考条件为 dim（IEC 61966-2-1），按 1.2/1.0 应有 ≤1.2×
的轻微对比项，实际观看环境高度可变，声明交付条件为 average 并记录此近似。
其余色貌现象（Hunt、Stevens、Helmholtz-Kohlrausch 等）需要绝对亮度——印片与
sRGB 都不钉死它——边界原样保留。内容与编码就此分离：**优选色彩再现（制造商
烘焙的故意偏离）是报告的内容，动它是背叛；surround 项是报告的编码，不换算
是失职。**

若需"影院拷贝原样搬上监视器"的 look（行业 2383 LUT 的习惯用法），按本合同
定义那不是翻译而是引用原文，须另立 `*_theatrical` 变体命名，不得占用胶片名。
（已实现：五条 2383 放映链各有 `*_theatrical` 引用变体，label 标注"影院放映
外观"，model 注记 quotation；引用的高对比使 AgX 拟合刻意超出设计条件，测试
门按声明系数 1.25 放宽——这是引用相对翻译的成本，如实报告。地板保留 2383
真实 Dmax（sRGB ~code 2），code-0 保护仍然成立。）

### 声明的计算边界（经三方对照确认）

1. **曝光依赖色彩**（interlayer/DIR、逐通道密度行为）——**已由光谱重建
   （2026-08-06 阶段四）收编**：运行时的逐通道比率增益机制整体退役，full 模式
   改为离线烘焙的完整光谱链 65³ LUT（后于 film v2 P3 拆分为
   `dngscan/data/film_v2/` 的 stock/print_state/b2 三分家族，单只 LUT 退役）；曝光依赖色彩由链自身携带，`channel_ratio_curve`
   的 v2 后继（`neutral_curve` 三元组）仍作为测量数据随预设发布。以下为该
   工作包的历史记录：
   - **数据裁定（2026-07-30）**：spektrafilm profile 不含按卷 DIR 耦合参数
     （agx-emulsion 的 DIR 是运行时通用默认值，属"magically derived"，按声明
     三原则弃用）；按卷实测数据 = 逐通道密度曲线本身（Portra 400 实测：
     B 层 γ0.561 / R 0.494 / G 0.470——蓝层先饱和即高光暖化的一阶来源）。
   - **一期（已完成）**：拟合器发射逐通道比率场
     `r_c(EV) = T_c(EV) / T_neutral(EV)`（与音调目标同源同衡同 surround 项），
     192 点入预设 `channel_ratio_curve`；不变量入测试（r_c(0)=1 由逐通道
     平衡构造保证、全域有界 [0.2, 5]）。
   - **二期（已完成，同日；2026-08-06 起由光谱重建替代——见下方注记）**：
     formation 运行时曾施加
     `out_c = C(EV_c) × r_c(EV_c) / r_c(EV_Y)`（`agx.channel_ratio_gain`）——
     中性像素 EV_c = EV_Y 时比率恒为 1（实数域构造精确，float32 亮度点积
     舍入 ~1e-7，测试钉定），**边界 #2 由构造保持**；色度越高通道曝光越散、
     效应自然浮现，无手调常数。实施语义：
     · 施加点在 **hue restore 之后、outset 之前**——实测差异是介质报告的
       内容，不是渲染器 hue 纪律（针对曲线源色摆）该稀释的对象；
     · SDR 与 HDR 在 `finish_formation` 同点施加同一 gain（HDR plan 经
       replace 继承 curve_preset）；域外插值钳制到端点，深白比率趋 1，
       扩展高光自然回中性，不污染 gain map——Ultra HDR 胶片导出实测过
       archive 档像素色度门；
     · 原生 C++ 核无比率级：`supports_agx` 对胶片预设如实拒绝、回退
       NumPy formation（48MP 帧 SDR 导出 6.4s 实测无显著回归；原生移植
       为后续测量项，非正确性需求）；
     · 安全轨 [0.25, 4]（高于实测最大比率商 ~3.7），是护栏不是塑形。
   - 残差中仍不表达的部分：DIR 的空间扩散（邻域效应）与真正的层间抑制
     动力学——需要按卷测量数据，维持声明边界。
2. **中性阶 cross-curve 不建模**：真实胶片的中性阶带染色（阴影偏青等），与
   本管线"中性轴不变"合同（防隐藏白平衡）冲突，取合同、弃染色。声明为非目标。
3. ~~相纸侧观看变换 = 恒等~~ **已由 §8.1 升格为推论**：相纸原生条件与交付
   条件同为 average surround，恒等项 = 1.0/1.0，是条件重合的结果而非假设。
   （历史记录保留：旧表述把恒等当边界声明，且未给电影链配 surround 项——
   这正是 §8.1 修订的起因。）
4. **HDR/SDR 双输出的观看亮度色貌不建模**（Hunt/Stevens 效应）：HDR 显示的
   更高绝对亮度会使相同色度显得更饱满、对比感更强，严格的 CAM（T-CAM 即为此
   而造）会按目标亮度调制饱和度；本管线 HDR 与 SDR 共享色度处理，gain-map
   架构里此项无建模，AgX path-to-white 仅在高光段部分缓解。声明假设：双输出
   观看亮度差异的色貌影响可忽略。解除此边界需要钉死交付亮度（媒介不提供）。
5. **前馈窗口不跟随镜前滤镜的色偏**：强滤镜单独使用（故意色偏）时材质滑出
   分离拟合的色度窗口，前馈按拟合域淡出为恒等——拒绝外推，不是失效
   （§2.2）；配对使用（滤镜+失配 WB）时两者相消、窗口全程有效。解除路径：
   分离矩阵拟合覆盖滤镜后激励区（需按滤镜重标定，成本高收益低，暂不做）。

### 外部互证（2026-07-30 完成）

| 通道 | 拟合密度尺度 | rms (stop) | max (stop) |
|---|---|---|---|
| R | 0.96 | 0.087 | 0.18 |
| G | 0.84 | 0.135 | 0.34 |

### 光谱印相（2026-07-30，接触印相模型二代）

起因是 Superia 样张的生硬观感（阴影突兀、颜色易转黑）与其"宽容"口碑的矛盾。
诊断链：端到端中段 gamma 富士链 1.5–2.0 vs 柯达链 1.05–1.45 → 上游语义核对
发现 profile 的 `density_curves` 是**逐染料量**而非 Status 通道读数（经各卷
`midscale_neutral_density` 光谱重建验证，rms 0.01–0.03）→ 通道捷径既误读了
数据，也跳过了染料旁带串扰的物理。

**模型**：`D(λ,e)=Σ染料量·染料谱+片基` → 相纸光谱感度 × TH-KG3 放大机
（3400K 黑体 × Schott KG3，出处 agx-emulsion）积分出逐通道印片曝光 → 相纸逐染料显影 →
印片光谱在声明观看光源下做相对比色（CIE 1931 → 线性 sRGB）。三个配套声明：

- **观看闪光**（现状注：介质原生标定落地后本条已撤销——标定链恒零杂光，
  黑位是介质自己的 Dmax 经声明环绕翻译；观看房间的闪光留给未来的观看模拟
  层。当年"阴影压碎"的真因由 surround 翻译与介质地板承担）：反射印片
  1.0%（IEC 61966-2-1）；暗环境投影介质为 0——此为 v2 时代口径。
- **曝光锚**：全局曝光偏移解"观看 Y=0.18"（测光表语义）——profile 的
  logE=0 是归一化约定不是场景中灰；旧的增益锚法曾把幻灯片中灰钉上肩部。
- **白点**：介质自己的 Dmin 态（含残留染料），非裸片基。

**第二轮判读（光谱模型 vs DiVERE）**：尺度阶梯消失（0.75/0.84/0.96 →
0.92/1.14/1.16），B 通道 rms **0.383→0.048**，三通道全部 ≤0.086 stop 合流——
同一把外部尺子先定量了旧简化的代价，又验证了升级的正确。缺失数据清单中
"Status M/A 响应函数"项就此**解除**（所需光谱数据全部在库）。

**全家拟合水平（介质原生 v4）**：25 支全部 rms ≤0.061（负片 0.014–0.044、
反转片 0.022–0.053、theatrical 引用 0.027–0.061）；反转片全部回到无钉界内点
解（velvia white +7.59），black_ev 数据决定。中性场以 `neutral_curve` 字段
随预设发布（可见域 Y>1e-3，[0.25,4] 护栏；护栏同为 full LUT 有界中性化的
声明边界）——它是测量记录，无运行时消费者：observe 的颜色走联合 LMS 色头，
full 走烘焙 LUT。

### 双模式分工（2026-07-30 合同修订：观察 vs 接管）

样张实证暴露了信任的维度差：**音调维度**经外部裁决（DiVERE 两轮），**色彩
维度**是无 oracle 的重建——Kodachrome 在模型改版间的巨大漂移、theatrical 的
怪异观感都住在色彩载体（比率场）里。而逐通道滚降本身就是颜色操作：让胶片
接管"显影侧颜色"必然与 AgX 的逐通道机制在同一算子位相争。合同据此确立
**分工画在数据可信边界上**：

> **胶片决定观察者看见了什么，AgX 决定怎么显影。** 分离侧（前馈，数据手册
> 第一手感色曲线）与音调签名（光谱印相拟合，外部验证）归胶片；显影侧颜色
> （逐通道行为、色相路径、褪白方式）归 AgX——它是本管线被打磨验证得最充分
> 的"优选再现"。

两模式（`--film-mode`，plan.film_mode）：

- **observe（默认）**：WB + 前馈 + 胶片音调曲线，颜色由 AgX 显影，负片另有
  联合 Y×M 色头场（outset 后施加）；原生内核照常加速（胶片预设在此模式下
  只是曲线参数）。
- **full（实验）**：胶片显影模型整体接管——`film_develop` 核：离线烘焙的
  光谱链 65³ LUT（输入纯场景线性 Rec.2020，前馈整体旁路），无 inset/outset/
  hue restore/punch，无色头，要求 AgX tone core；AgX 只保留交付端色域安全。
  **色彩侧无外部验证**的标注随模式携带；暂仅 SDR（CLI 对 ultrahdr 组合
  显式拒绝）。
- 关闭 `--film` 即纯 AgX，不变。

色彩维度的解锚路径（缺失数据清单追加）：真胶片拍摄色卡的扫描/翻拍对照集——
有此 oracle 前，full 模式的任何色彩重建版本都只是模型偏好，不得声称忠实。

**三管线对照与原型对应**（2026-07-30 复盘，§8 对照审计的补遗）：

| | Kelly / ACES 胶片仿真 | FilmLight / T-CAM | dngscan |
|---|---|---|---|
| 渲染槽位由谁占据 | 胶片链本身（ADX10→负片→2383；胶片链即 OOTF） | 设计的 CAM；胶片 look 为分离上层 | AgX；双模式明确槽位归属 |
| 色彩再现数据源 | 柯达第一方实测（ADX/APD、2383 LUT） | 色貌科学+设计；look 走 virtual shoot-out | AgX=darktable 谱系冻结；胶片色彩=三手重建（无 oracle） |
| 观看条件 | 影院暗环境烤入 | CAM 显式建模（含 HDR 族） | surround 常数翻译 + IEC 闪光声明 |

**observe 模式 ≈ FilmLight 原型**（自家 DRT 坐镇，胶片为分离的观察者层）；
**full 模式 ≈ Kelly 原型**（胶片链占据渲染槽）。

**风格配对（observe 的声明 look 层，2026-07-30）**：当时的观感评估结论为
"observe 稳而淡、full 浓而坏"（2026-08-10 实测已推翻其中 "full 浓" 的部分：C-41
负片在 full 下的 chroma 只有 observe 的 0.65 倍，见
[外观层 P0 基线](FILM_APPEARANCE_P0_BASELINE.zh-CN.md)），
补味走已验证机制而非重新掺入无锚重建——
`FILM_STYLE_PAIRINGS`（film_curve.py）按卷口碑给每个预设配一组
（前馈分离超驱动强度, AgX primaries 几何），如 Velvia→(×1.6, punchy)、
Kodachrome→(×1.4, muted)、Vision3→(×1.2, muted)。三条属性：全部走已验证
机制（前馈有界超驱动 + AgX 自家几何词汇）；**标注编辑决定，不冒充测量**
（初稿 2026-07-30，用户观感为最终裁量）；combo 展开可见、显式给出的单层
值优先——没有烘焙。full 模式不吃配对（胶片显影模型自带性格）。
这正是 FilmLight 结构的完整复刻：稳定 DRT + 分离的 look 层。Kelly 原型成立的前提是
第一方实测色彩数据——**行的是数据，不是管线形状**；full 模式与之同构而
数据不同级，这就是它标注实验的准确理由。该对照同时暴露了 §8 初版审计的
方法论缺口（只核对已建成机制、未对可预见扩张跑碰撞推演），教训入
工程决策记录案例 9 续二。

### 放大机色头（2026-08-04：把印相决策交还给人）

暗房反馈指出本合同建模的一个盲点：彩色负片没有"自己的颜色"——底片是中间
记录，最终颜色在放大机下由**人**决定，色头 Y/M 分色滤镜档位就是那次决策。
接触印相拟合器完整建模了放大机（TH-KG3：3400K 黑体 × Schott KG3，相纸
光谱感度 + printer lights 中性解），但滤镜档位一直烘死在中性档：负片预设出厂自带一个固定的"印相决定"，
用户没有旋钮，被迫误用拍摄端 WB 或 LUT 层去表达一个本属印相端的意图。

**机制（构建期光谱推导 + 运行时插值）**：printer lights k 本就是拟合器里
色头的数字孪生（fit_film_curve.py 的注释原文如此）。色头功能把它参数化：
构建期把 Y（M）滤镜按 CC 密度放进放大机光路——衰减相纸蓝敏（绿敏）层曝光
10^-d——重曝相纸并按暗房惯例重解曝光时间（中灰亮度回 0.18），发布
逐通道显示增益场（现状注：本段的"CC 小网格 30/60/120/200 + Y×M 乘性可分"
是首版设计，已被**联合 Y×M 全档位场**取代——0..200 步进 5 的 41×41 档位
逐一联合求解、单次重定时，乘性可分近似被联合解以 ~0.35 档 RMS 否证后废除；
场以 Bradford-LMS 对角增益发布于自适应共享 EV 节点，npz schema 4 且 SHA-256
钉在预设 JSON 里）；运行时按档位直接索引、仅插值 EV，在 **AgX outset 之后**
的标定基底施加。
**声明的近似**：增益场沿中性斜坡推导（对含色场景按场景亮度 EV_Y 取值）。方向背暗房口诀且
经渲染级验证：成片偏什么色加什么滤镜。

**色彩模型冻结豁免的判定**：此功能**不改动显影色彩模型**——放大机灯泡、
相纸感度、印相积分全部是拟合器既有元件，色头只是把其中一个常数（printer
lights 的中性档位）变成声明输入参数。AgX 显影侧（inset/outset、hue restore、
褪白）一行未动；两档全零时逐字节等于现状（渲染级 sha 验证）。这与
"declared input"谱系（WB 声明、镜前滤镜、前馈强度）同类，与"重建色彩载体"
（比率场、full 模式）不同类——后者受 oracle 缺席约束，前者是用户意图的
物理单位表达。

**边界**：仅负片预设（预设新增 `process` 分类字段）；反转片如实无此控件——
幻灯片自身就是显示介质，物理上不存在印相环节（GUI 隐藏、CLI/服务端拒绝）。
色头**仅 observe 模式**（现状注：立案时设想"印相决策独立于显影分工、两
模式同吃"，后被 full 的实现方式取代——接管 LUT 把印相链固定烘焙于 0CC，
完整光谱链之后不能再追加中性轴近似，full+色头在 CLI/GUI/plan 编译一律显式
拒绝）；observe 下原生内核在档位非零时按既有先例让位 NumPy 路径。
### 层间漂移声明开关（2026-08-04：`--film-crossover`，plan.film_crossover）

> **现状注**：本节的开关**语义**（off=中性轴安全轨为默认、datasheet=声明放出
> 实测层间数据、默认 off 的冻结理由与 oracle 裁决路线）仍然生效，但**实现**
> 已随 full 模式换代：`channel_ratio_field`/`agx.channel_ratio_gain` 已退役，
> 现行实现在烘焙 LUT 内部——**off** = 数字中性化变体（各通道除以随 npz 发布
> 的有界 cast 曲线，[0.25,4] 轨道，t-路径保亮度），**datasheet** = 光谱链
> 原样（中灰由 q 求解锚定）。开关仅在 full 模式有意义；observe 下两档逐字节
> 相同。现状见 ARCHITECTURE。以下为立案时的原始论证。

**数据来源**：full 模式的逐通道比率场 r_c(EV)（当年的
`film_curve.channel_ratio_field`，
tools/fit_film_curve.py 光谱印相拟合的实测输出）本身已含 crossover 信息——
中灰锚定读数（velvia100）：EV−4 处 B 1.606 / R 1.008（B/R≈1.59），EV−2 处
B 1.327 / R 0.894（B/R≈1.48），EV+1 处 B 1.040（轻微偏蓝）。方向与 Dehancer
实测的 Velvia 阴影冷差一致，量级远超拟合噪声底。但现行归一化
`gain_c = r_c(EV_c)/r_c(EV_Y)`（反隐藏白平衡安全轨）把中性轴上的分区染色
（=crossover）按构造抵消——数据在场里，语义上被锁住。

**锚定语义**（两档；立案时拟以 `agx.channel_ratio_gain` 单点实现，现由
LUT 内的有界中性化承担）：

- `off`（默认）：现状逐字节不变。锚 = 像素自身 formation 亮度 EV；中性轴
  增益恒等 1，反隐藏 WB 契约全轴成立。
- `datasheet`：锚 = 中灰（EV0，逐通道标量 r_c(0)）。中灰严格 WB 保真
  （契约核心保留），中性轴两端按实测层间数据漂移——阴影冷、亮端按场——
  摄影语义的 crossover。现有 [0.25, 4] 安全轨照用。仅
  film_mode=full 且预设携带比率场时有意义，其余组合零开销零改变。

**默认 off 的冻结理由**：比率场的色彩维度仍是无外部 oracle 的重建（本文
"双模式分工"节的信任边界原样适用）；把已测数据"放出来"是声明动作，
把它设为默认是裁决动作——后者需要真胶片色卡对照集（缺失数据清单）先行。
实拍对表（DSC00225 + velvia100 full）显示 datasheet 模式把暗部 Oklab b 轴
从 off 模式的读数向 Dehancer 参照方向移动，但量级由场数据说了算，不加
缩放因子——过冲本身是测量结果，缩放决策留给 oracle 之后。

**oracle 裁决路线**：真胶片拍摄色卡（含灰阶斜坡）的扫描/翻拍对照集落地后，
逐 EV 对表比率场的中灰锚定读数；方向与量级双过门则将 `datasheet` 转正为
full 模式默认，`off` 降为兼容开关；量级不过门则按对照集重标定比率场，
开关语义不变。
